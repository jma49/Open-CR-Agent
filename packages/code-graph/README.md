# @open-cr-agent/code-graph

The tree-sitter symbol extractor of [Open-CR-Agent](https://github.com/jma49/Open-CR-Agent), the multi-agent code reviewer: definitions and uses per file, for the impact analysis, cached by git blob id. Most users want [`@open-cr-agent/cli`](https://www.npmjs.com/package/@open-cr-agent/cli) (the `ocra` command) and the [manual](https://ocracloud.com). All packages share one version. Apache-2.0.
