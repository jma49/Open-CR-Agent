# @open-cr-agent/vcs-platform

What the platform adapters of [Open-CR-Agent](https://github.com/jma49/Open-CR-Agent), the multi-agent code reviewer, share: the summary comment and the review state it carries, inline comment text, and the rules for who may override, dismiss or answer ocra. Most users want [`@open-cr-agent/cli`](https://www.npmjs.com/package/@open-cr-agent/cli) (the `ocra` command) and the [manual](https://ocracloud.com). All packages share one version. Apache-2.0.
