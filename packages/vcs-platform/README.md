# @open-cr-agent/vcs-platform

What the code review platform adapters of [Open-CR-Agent](https://github.com/jma49/Open-CR-Agent), the multi-agent code reviewer, share: the summary comment and the review state it carries, the text of inline comments, and the rules for who may override, dismiss or answer ocra. Most users want [`@open-cr-agent/cli`](https://www.npmjs.com/package/@open-cr-agent/cli), which provides the `ocra` command and installs this package; see the [manual](https://ocracloud.com). All `@open-cr-agent` packages are released together at one version. Apache-2.0.
