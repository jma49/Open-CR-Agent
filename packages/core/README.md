# @open-cr-agent/core

The domain types, pipeline stages and plugin contract of [Open-CR-Agent](https://github.com/jma49/Open-CR-Agent), the multi-agent code reviewer; see the [plugin guide](https://ocracloud.com/en/docs/plugins). Most users want [`@open-cr-agent/cli`](https://www.npmjs.com/package/@open-cr-agent/cli) (the `ocra` command) and the [manual](https://ocracloud.com). All packages share one version. Apache-2.0.
