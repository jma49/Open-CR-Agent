# @open-cr-agent/vcs-gitlab

The GitLab merge request adapter of [Open-CR-Agent](https://github.com/jma49/Open-CR-Agent), the multi-agent code reviewer, for GitLab.com and self-managed GitLab. Most users want [`@open-cr-agent/cli`](https://www.npmjs.com/package/@open-cr-agent/cli) (the `ocra` command) and the [manual](https://ocracloud.com). All packages share one version. Apache-2.0.
