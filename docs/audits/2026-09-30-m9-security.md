# Security audit, 2026-09-30 (M9 "Reach and trust")

This audit covers the M9 batch, `9ed60cd..9c1ec97` on `main` (21 commits):
- the shared platform layer (`vcs-platform`, ADR-0016), the GitLab adapter and `--mr`;
- SARIF output;
- OpenAI-compatible providers (ADR-0017);
- the container image;
- release hardening and spend-limit reporting.

A background agent read the diff. It checked its claims with read-only probes against the built packages, the pinned OpenCode binary, and GitLab's and comrak's sources. Before each fix, the finding was confirmed again (column "Confirmed by"). Two findings come from the npm hardening done in the same session (S13, S14).

Policy decisions went to Claude Fable 5.1:
- refuse providers from an unpinned `extends`;
- refuse, rather than guess, a GitLab API host for a self-managed `origin`;
- count no GitLab resolution a push may have made;
- follow the SARIF specification on braces;
- how to document who controls the pipeline, decided over two rounds. The first answer asked for an external CI configuration as the default recipe. The second round dropped it, because project variables reach every job in the pipeline, including the author's.

No model credit was spent.

Severity:
- **P0:** exploitable in normal use.
- **P1:** a real weakness under realistic conditions.
- **P2:** a weakness that needs an unusual position (the host of a shared configuration, a compromised dependency, a local run against a self-managed instance).
- **P3:** an edge case or hygiene.

**Verdict:** every finding is fixed, except S3, which no code can fix. For S3 the manual now says where the review can be trusted and what limits the rest. Three follow-ups are filed (#288–#290).

## Accepted

- **Zero-width spaces inside quoted code.** The neutralizer does not know about code spans, so the spaces it adds also land in code a finding quotes. They are invisible but copied along. #288.
- **Issue references.** `#12` or `group/project#3` in model text still link and leave a cross-reference on the referenced issue. They notify nobody the way a mention does. A literal `&#64;` now shows `#64`, which links the same way.

## Checked and sound

- **Override.** Unchanged by the refactor (old and new adapters diffed). It needs the full head commit id and an unedited comment from someone other than the author and ocra; the summary is excluded. GitLab's `/members/all/:id` gives effective access, so group-share caps apply.
- **Write access by user id.** Ids come from the API's author and resolver objects, and the `/users` fallback matches exactly.
- **Summary state.**
  - It is found by the bot's exact login, must end the note, and is bounded by zod.
  - GitLab's `lastEditedBy` is `Note#updated_by`, or the ghost user.
  - An unknown editor makes the state untrusted, and fails closed for replies and for ocra's own threads.
- **Planting ocra's own threads** needs the bot's token. Model text cannot produce `<!--`, and the marker is matched on the first line.
- **GitLab quick actions.**
  - Every line start that GitLab's Ruby regex sees is one the neutralizer handles, including after GitLab deletes `\r`.
  - Every interpolation that starts a line is either neutralized or a constant.
- **GitLab mapping.**
  - System notes and diff notes are filtered.
  - Positions use the API's `diff_refs` over a merge-base diff.
  - Tokens never appear in errors, and a POST is not retried on a 5xx.
- **`baseUrl` loopback check.** It holds against userinfo, `127.0.0.1.evil.com`, `\@`, IPv4-mapped IPv6, and hex, decimal and short IPv4 forms. `GITLAB_*` and `CI_*` are never copied by prefix.
- **`--mr` inputs.** The iid and commit ids are validated before git runs. Configuration, rules and `AGENTS.md` come from `start_sha`, and plugins are off.
- **SARIF escaping.** Backslashes are escaped before brackets, and URIs are encoded per path segment.
- **Provenance and image.**
  - `provenance.mjs` checks the subject digest against the tarball's integrity, and checks the repository, workflow path and tag.
  - `npm audit signatures` runs first.
  - A release image refuses to build from source.
