## 环境要求

- **Node.js 22.19** 或更高版本
- **Git**
- 至少一个模型供应商的 API key

默认的 OpenCode 运行时作为可选依赖一并安装；不想装它，见[不装 OpenCode](#不装-opencode)。

## 从 npm 安装

```bash
npm install -g @open-cr-agent/cli
ocra --version
```

更新：`npm install -g @open-cr-agent/cli@latest`。卸载：`npm uninstall -g @open-cr-agent/cli`。

也可以不安装直接运行：

```bash
npx @open-cr-agent/cli review
```

npm 11.16 及更高版本会提示 `opencode-ai` 有一个不在 `allowScripts` 允许范围内的安装脚本，npm 12 会直接拦下它。ocra 不需要它（能在平台包里找到二进制文件），所以不必放行。

## 不装 OpenCode

OpenCode 运行时 `@open-cr-agent/runtime-opencode` 约占一次安装 175 MB 中的 165 MB。如果所有模型都在声明的端点上，并且配置设了 `"runtime": "direct"`（见[选择运行时](./providers#选择运行时)），就可以不装它。`npm install -g` 总会安装可选依赖，所以请装进一个单独的目录：

```bash
npm install --prefix ~/.ocra --omit=optional @open-cr-agent/cli
~/.ocra/node_modules/.bin/ocra --version   # 或者把 ~/.ocra/node_modules/.bin 加进 PATH
```

作为项目依赖安装时，`--omit=optional` 同样适用。`ocra review --plan` 不需要运行时。用默认的 `opencode` 时，审查会在调用任何模型之前以退出码 2 停下，并给出两种解决办法：设置 `"runtime": "direct"`，或者安装与 ocra 版本完全一致的运行时（`npm install --prefix ~/.ocra @open-cr-agent/runtime-opencode@<版本>`）。

在 GitHub Action 里，输入 `opencode: false` 起同样的作用（见 [GitHub](./github#运行时)）。

## 容器镜像

从 0.2.0 起，每个发布版本都提供 amd64 和 arm64 的容器镜像 `ghcr.io/jma49/ocra:<版本>`：刚发布的包，按 GitHub Action 的方式安装（依赖版本固定，校验签名和 provenance），带有 git，以非特权用户 `node` 运行。

```bash
docker run --rm --user "$(id -u):$(id -g)" --volume "$PWD:/repo" \
  --env GEMINI_API_KEY ghcr.io/jma49/ocra:0.7.0 ocra review --from main
```

0.2.0 之后的镜像以 `ocra` 为入口点，所以 `docker run <镜像> review --from main` 就够了；前面多写一个 `ocra` 对每个镜像都有效。以你自己的用户运行，它才能写 `.ocra/sessions/`；模型密钥和 `OCRA_*` 变量用 `--env` 传入。核对镜像来源见[校验发布版本](./stability#校验发布版本)。

## 从源码安装

参与开发 ocra 或运行未发布的版本：

```bash
git clone https://github.com/jma49/Open-CR-Agent.git
cd Open-CR-Agent
npm install
npm run build
npm link --workspace @open-cr-agent/cli
```

`npm link` 把 `ocra` 放到 PATH 上。更新：

```bash
git pull && npm install && npm run build
```

卸载：`npm unlink --global @open-cr-agent/cli`。

或者不 link，直接运行构建好的 CLI：

```bash
node /path/to/Open-CR-Agent/packages/cli/dist/main.js review
```

## OpenCode 二进制文件

ocra 先在 `opencode-ai` 的平台包里找 OpenCode，再到 `opencode-ai/bin/`（其安装脚本放置的位置）里找。两处都没有时，手动指定：

```bash
export OCRA_OPENCODE_BIN=/path/to/opencode
```
